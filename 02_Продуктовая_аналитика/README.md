# Модуль 2: Продуктовая и клиентская аналитика

Этот модуль посвящён анализу поведения пользователей и расчёту ключевых продуктовых метрик.

## Содержание модуля

*   `Когортный_анализ_и_расчёт_LTV.xlsx` — Анализ удержания клиентов по когортам и расчёт пожизненной ценности (LTV).
*   `Сравнение_методик_расчёта_Lifetime.xlsx` — Сравнение когортного и цепного (некогортного) методов расчёта времени жизни клиента.
