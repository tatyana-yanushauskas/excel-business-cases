# Excel для бизнес-аналитики: практические кейсы

В репозитории собраны решения реальных бизнес-задач с помощью Excel и Google Sheets.  
Кейсы охватывают ключевые направления работы аналитика: от финансового моделирования до продуктовой аналитики.

## 📁 Структура

**Финансовое моделирование**  
Расчёты, прогнозы, юнит-экономика, оптимизация ресурсов.

**Продуктовая и клиентская аналитика**  
Когортный анализ, LTV, Retention, поведение пользователей.

**Визуализация данных**  
Дашборды и бизнес-графики для презентации метрик.

**Обработка и автоматизация**  
Очистка данных, объединение таблиц, подготовка к анализу.

В каждом разделе — файлы с решениями и выводами.

## 🎯 О чём этот репозиторий

Показать, как с помощью Excel решать прикладные бизнес-задачи:  
от поиска точек роста до контроля ключевых показателей.
