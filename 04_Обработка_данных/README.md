# Модуль 4: Обработка и автоматизация данных (ETL)

Модуль показывает работу с «сырыми» данными: их извлечение, очистку и объединение из разных источников.

## Содержание модуля

*   `Фильтрация_VLOOKUP_анализ_уроков.xlsx` — Работа с двумя связанными таблицами, фильтрация, `ВПР`.
*   `Сводные_таблицы_анализ_выплат.xlsx` — Анализ структуры данных и расчёт выплат с помощью сводных таблиц.
*   `Импорт_PowerQuery_PowerPivot.xlsx` — Импорт из TXT/CSV, работа с большими данными через Power Pivot, веб-запрос.
*   `GoogleSheets_веб_скрапинг_VLOOKUP` — Работа в Google Sheets: импорт данных из интернета, очистка, объединение таблиц.
