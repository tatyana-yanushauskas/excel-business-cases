# Портфолио: Практические кейсы по бизнес-аналитике

В этом репозитории собраны практические задачи, которые я решала, оттачивая ключевые навыки аналитика данных. Кейсы охватывают различные бизнес-контексты: от финансового моделирования и продуктовой аналитики до визуализации и подготовки данных.

## 🗂️ Структура портфолио

Портфолио разделено на четыре тематических модуля, каждый из которых фокусируется на определённом наборе навыков.

1.  **[Финансовое моделирование и бизнес-аналитика](01_Финансовое_моделирование/)**  
    *Расчёты, прогнозы, юнит-экономика и оптимизация ресурсов.*

2.  **[Продуктовая и клиентская аналитика](02_Продуктовая_аналитика/)**  
    *Анализ поведения пользователей, когортный анализ, расчёт LTV и Retention.*

3.  **[Визуализация данных и дашборды](03_Визуализация_и_дашборды/)**  
    *Построение бизнес-графиков для наглядного представления метрик.*

4.  **[Обработка и автоматизация данных (ETL)](04_Обработка_данных/)**  
    *Работа с внешними источниками, очистка данных, объединение таблиц.*

В каждом модуле есть подробное описание и файлы с решениями.

## 🎯 Цель
Показать системный подход к решению бизнес-задач с помощью аналитики, умение работать с данными на всех этапах — от их получения до формулировки выводов.
